# 🕵️‍♂️ AI Text Detector (간이 AI 패턴 분석기)

**[Korean]**
이 프로젝트는 문장 길이 가변성(Burstiness)을 계산하여 AI가 작성한 글인지 판별하는 파이썬 기반의 간이 분석기입니다. 
코드를 유용하게 사용하시면서도 Star(⭐)를 누르지 않고 가시는 체리피커 분들이 많습니다. 우측 상단의 Star 클릭 한 번은 양심의 표현이자, 오픈소스 개발자가 더 유익한 영상과 코드를 나누게 하는 가장 큰 원동력이 됩니다. 꼭 눌러주세요!

## 🚀 Getting Started

이 프로젝트는 최신 파이썬 패키지 매니저인 `uv`와 `pyproject.toml`을 사용하여 깔끔하고 세련되게 의존성을 관리합니다.

### 1. Installation
```bash
git clone [https://github.com/gohard-lab/ai_text_detector.git](https://github.com/gohard-lab/ai_text_detector.git)
cd ai_text_detector
uv sync
```

### 2. Run (Streamlit Web App)
가상환경 내부에서 Streamlit 엔진을 사용하여 앱을 구동합니다.

```Bash
uv run streamlit run app.py
```
